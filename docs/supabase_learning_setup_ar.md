# إعداد Supabase للكورسات والاشتراكات والفيديوهات

لم ينفذ التطبيق أي تعديل في Supabase. نفّذي الخطوات التالية بنفسك من المتصفح.

## 1. إنشاء الجداول والسياسات

1. افتحي مشروع Supabase ثم **SQL Editor → New query**.
2. انسخي محتوى [supabase_learning_setup.sql](supabase_learning_setup.sql) كاملًا.
3. الصقيه في المحرر واضغطي **Run** مرة واحدة.
4. افتحي **Table Editor** وتأكدي من وجود:
   - `courses`: بيانات الكورسات.
   - `enrollments`: يربط المستخدم بالكورس بعد الضغط على **Start Course**.
   - `course_videos`: معلومات فيديوهات كل كورس.

التطبيق لا يستخدم `currency` أو `is_published`. إذا كانا موجودين من جدول سابق، يمكن تركهما؛ لن يقرأهما التطبيق ولن يؤثرا عليه.

## 2. إنشاء مكان ملفات الفيديو

1. افتحي **Storage** واضغطي **New bucket**.
2. اكتبي الاسم حرفيًا: `course-videos`.
3. اتركيه **Private** ولا تفعّلي Public bucket.
4. لكل كورس، انسخي قيمة `id` من جدول `courses`.
5. داخل Bucket أنشئي مجلدًا اسمه يساوي `id` الخاص بالكورس، مثل:

   `2de1c0c4-1d14-4ee0-bfb0-e8ef4d7d7640`

6. ارفعي فيديوهات ذلك الكورس داخل مجلده.

المسار النهائي يجب أن يكون بالشكل:

`<course_id>/<file_name>.mp4`

السياسة الموجودة في ملف SQL تستخدم اسم المجلد لمعرفة الكورس، ولا تسمح بجلب الملف إلا للمستخدم الموجود في `enrollments` لهذا الكورس.

## 3. إضافة بيانات الفيديو

افتحي **Table Editor → course_videos → Insert row** ثم أدخلي:

| العمود | ما يكتب فيه |
| --- | --- |
| `course_id` | اختاري `id` الخاص بالكورس |
| `title` | عنوان الفيديو أو الدرس |
| `description` | وصف قصير، ويمكن تركه فارغًا |
| `video_path` | المسار داخل Bucket، وليس الرابط الكامل |
| `thumbnail_url` | رابط صورة عامة للفيديو، ويمكن تركه فارغًا |
| `position` | ترتيب الفيديو داخل الكورس: `1` ثم `2` ثم `3` |

اتركي `id` و`created_at` على القيم الافتراضية. مثال `video_path`:

`2de1c0c4-1d14-4ee0-bfb0-e8ef4d7d7640/01-introduction.mp4`

لا تكرري قيمة `position` داخل الكورس نفسه.

## 4. ما يحدث في التطبيق

- زر **Start Course** يضيف صفًا تلقائيًا إلى `enrollments` باسم المستخدم والكورس.
- لا تضيفي صفوف `enrollments` يدويًا.
- تبويب **My Courses** يقرأ الكورسات المرتبطة بالمستخدم الحالي فقط.
- الضغط على كورس من Home يفتح التفاصيل فقط.
- الضغط على الكورس من My Courses يفتح فيديوهاته.
- عند فتح فيديو، ينشئ التطبيق رابطًا مؤقتًا لمدة ساعة لملف الفيديو الخاص.
- الاسم والبريد وتغيير كلمة المرور تستخدم Supabase Auth، لذلك لا يلزم جدول Profile.
- إذا غُيّر البريد، قد يطلب Supabase تأكيد البريد الجديد بحسب إعدادات Authentication في المشروع.
